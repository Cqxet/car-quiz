# Araba Testi

Araba tahmin oyunu. Her soruda fotoğrafın rastgele bir köşesi yakın gösterilir (ön veya arka; yan görünüm yok). Bilemeyince kare büyür. Wikimedia’dan yirmi bin civarı araba yüklenir.

## Vercel’e koyma

Kod GitHub’da: https://github.com/Cqxet/car-quiz

Vercel GitHub reposunu yayınlar (Cursor kopyası otomatik gitmez).

1. https://vercel.com → Continue with GitHub (Cqxet).
2. Add New… → Project.
3. car-quiz seç → Import.
4. Framework Next.js → Deploy.
5. Çıkan vercel.app linkini aç.

```bash
npx vercel --prod
```
